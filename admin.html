Export / Data

Data is stored in your browser (localStorage) until you export the JSON and upload it to GitHub.

  • Download counts.json – Saves the artefact counters for the homepage.
  • Download all module JSON – Saves all artefacts for every module.
  • Clear local data – Deletes all locally stored data in the browser.

Upload the downloaded files to assets/data/ in your repository. The homepage shows module badges, and the module pages can load and display the data.
