
# MSc Cyber Security e‑Portfolio

Clean starter for a GitHub Pages e‑portfolio with a dark, modern layout.
Name is masked as "Your Name" throughout.

## Structure
- `index.html` — Home with About Me section and module tiles
- `about.html`, `contact.html`, `cv.html`
- `module-*.html` — One page per module with required sections
- `admin.html` — Upload UI placeholder (no backend yet)
- `assets/css/styles.css` — Styles
- `assets/js/main.js` — Small JS (tabs, year)

## Deploy on GitHub Pages
1. Create a new **public** repo on GitHub.
2. Upload all files in this folder to the repo root.
3. Go to **Settings → Pages** and set source to the **main** branch (root).
4. Wait for Pages to publish and open the site URL.
